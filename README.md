## 🧬 About Me

I'm an **AI Engineer** at **TechnoSmart (Virtual Teams & Solution)**, where I build production voice-AI infrastructure that handles real inbound and outbound calls at scale — not demos. I own the systems end to end: from the LLM retrieval pipeline down to the AWS IAM policy that almost took production offline at 2am.

My core focus is **agentic and conversational AI** — voice agents built on Retell AI and Twilio, hybrid retrieval architectures (BM25 + dense embeddings + Reciprocal Rank Fusion + Cohere Rerank), and CRM integration layers designed with clean adapter interfaces so a new CRM is a plug-in, not a rewrite. I pair that with a DevOps mindset: ECS deployments, EventBridge-driven batch scheduling, and cost-modeling infrastructure against real Twilio/Retell invoices, not assumptions.

currently_learning:

  - Kubernetes
  - DSA under time pressure (14-day rotating curriculum)

open_to:
  - AI Engineer roles

  - Backend / Platform Engineering roles at product-driven MNCs
